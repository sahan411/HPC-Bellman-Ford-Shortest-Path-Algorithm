\section{Executive Summary}

This report documents the comprehensive analysis, optimization, and implementation of the HPC Bellman-Ford Shortest Path Algorithm across five parallel computing paradigms. Four critical bugs were identified and fixed, resulting in correct algorithm behavior across all implementations.

\hyperref[contents]{\small Back to Table of Contents}

\section{Introduction}

\subsection{Algorithm Overview}

The Bellman-Ford algorithm finds the shortest paths from a single source vertex to all other vertices in a weighted directed graph. Unlike Dijkstra's algorithm, it handles negative edge weights and detects negative cycles.

\begin{itemize}
    \item \textbf{Time Complexity:} $O(V \times E)$
    \item \textbf{Space Complexity:} $O(V)$
    \item \textbf{Best Case:} $O(E)$ with early termination
    \item \textbf{Worst Case:} $O(V \times E)$ with negative cycles
\end{itemize}

\subsection{Bug 1: OpenMP Race Condition}

\subsubsection*{Problem Description}

Multiple threads writing to shared \texttt{dist[]} array without synchronization, causing lost updates.

\subsubsection*{Code Before (UNSAFE)}

\begin{lstlisting}[language=C, caption=OpenMP implementation with race condition]
// BEFORE: UNSAFE - Race condition
for (int v = 0; v < V; v++) {
    int new_dist = dist[u] + graph->edges[u][v].weight;
    if (new_dist < dist[v]) {
        dist[v] = new_dist;  // UNSAFE: Multiple threads writing
        updated = 1;
    }
}
\end{lstlisting}

\subsubsection*{Code After (SAFE)}

\begin{lstlisting}[language=C, caption=OpenMP implementation with critical section]
// AFTER: SAFE - Protected with critical section
#pragma omp critical
{
    if (new_dist < dist[v]) {
        dist[v] = new_dist;
        updated = 1;
    }
}
\end{lstlisting}

\subsection{Bug 2: MPI Reduction Operation Error}

\subsubsection*{Problem Description}

Using \texttt{MPI\_MAX} instead of \texttt{MPI\_LOR} for boolean aggregation is semantically incorrect.

\subsubsection*{Code Before}

\begin{lstlisting}[language=C, caption=MPI with incorrect reduction]
// BEFORE: WRONG - Using MAX for boolean OR
MPI_Allreduce(&updated, &global_updated, 1, MPI_INT, MPI_MAX, MPI_COMM_WORLD);
\end{lstlisting}

\subsubsection*{Code After}

\begin{lstlisting}[language=C, caption=MPI with correct reduction]
// AFTER: CORRECT - Using LOR for boolean aggregation
MPI_Allreduce(&updated, &global_updated, 1, MPI_INT, MPI_LOR, MPI_COMM_WORLD);
\end{lstlisting}

\subsubsection*{Impact}

\begin{itemize}
    \item Semantically correct boolean aggregation
    \item Improved code readability
    \item Better maintainability
    \item Functional equivalence maintained
\end{itemize}

\subsection{Bug 3: Hybrid Race Condition}

\subsubsection*{Problem Description}

Hybrid MPI+OpenMP implementation inherited the OpenMP race condition in its local parallel loop.

\subsubsection*{Solution}

Applied the same critical section protection as Bug 1 to the OpenMP component within the hybrid model.

\subsubsection*{Verification}

Results now match Serial implementation:
\begin{itemize}
    \item Distance values: Identical
    \item Cycle detection: Identical
    \item Execution time overhead: Acceptable
\end{itemize}

\subsection{Bug 4: CUDA Premature Termination}

\subsubsection*{Problem Description}

CUDA implementation terminated prematurely due to incorrect update detection logic.

\subsubsection*{Code Before (INCORRECT)}

\begin{lstlisting}[language=C, caption=CUDA with incorrect termination logic]
// BEFORE: INCORRECT - Only detects some updates
if (old > new_dist)
    atomicOr(&any_update, 1);
\end{lstlisting}

\subsubsection*{Code After (CORRECT)}

\begin{lstlisting}[language=C, caption=CUDA with correct termination logic]
// AFTER: CORRECT - Detects all meaningful updates
if (old != new_dist)
    atomicOr(&any_update, 1);
\end{lstlisting}

\section{Practical Work}

\subsection{Implementation Overview}

Five parallel implementations of Bellman-Ford algorithm:

\begin{enumerate}
    \item \textbf{Serial}: Baseline single-threaded C implementation
    \item \textbf{OpenMP}: Shared memory parallelism with pragma directives
    \item \textbf{MPI}: Distributed memory for multi-node systems
    \item \textbf{Hybrid}: Combines MPI (inter-node) + OpenMP (intra-node)
    \item \textbf{CUDA}: GPU acceleration with NVIDIA CUDA
\end{enumerate}
